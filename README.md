# Customer Shopping Behavior Analysis

## Project Overview

This project focuses on analyzing customer shopping behavior using Python. The main objective is to identify purchasing patterns, understand customer preferences, and discover meaningful business insights from customer transaction data.

## Objectives

- Analyze customer purchasing behavior.
- Identify the highest revenue-generating product categories.
- Understand customer spending patterns.
- Analyze seasonal sales performance.
- Identify popular payment methods.
- Compare spending behavior between subscribed and non-subscribed customers.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

**Dataset:** Customer Shopping Behavior Dataset

The dataset contains customer shopping and transaction information, including product categories, purchase amounts, gender, seasons, payment methods, and subscription status.

## Key Business Insights

1. **Product Category:** Clothing generated the highest revenue of $104,264, representing approximately 44.7% of total revenue.
2. **Subscription Analysis:** Non-subscribed customers generated higher total revenue ($170,436) compared to subscribed customers ($62,645).
3. **Average Spending:** The average purchase amount was approximately $59.87 for non-subscribed customers and $59.49 for subscribed customers.


4. Open the project folder in VS Code or Jupyter Notebook.

6. Run the notebook cells to explore the analysis and visualizations.
